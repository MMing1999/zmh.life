# Figma 生命阶段图设计规范

## 设计概览
基于 Figma 设计 (node-id: 859:27711) 的生命阶段时间轴组件

## 设计规范

### 字体
- **主字体**: `Fusion_Pixel_12px_Monospaced_zh_hans` (Regular)
- **标题**: 16px, 黑色, 居中
- **年份/年龄**: 12px, 黑色, 居中
- **事件文字**: 12px, 黑色, 左对齐
- **"现在"标记**: 12px, 红色 (#c41616)

### 颜色
- **背景**: 白色 (#FFFFFF)
- **边框**: 黑色 (#000000), 1px solid
- **文字**: 黑色 (#000000)
- **"现在"标记**: 红色 (#c41616)
- **编辑提示**: 灰色 (#acacac)

### 布局
- **容器**: 白色背景，黑色边框，312px 高度
- **时间轴**: 水平箭头线，位于 122px 高度
- **时间点间距**: 72px 宽度（每个时间点）
- **垂直间距**: 6px gap
- **标题位置**: 顶部 0px，左侧 32px（居中）

### 时间点结构（从上到下）
1. **黑色小方块**: 10px × 10px，位于时间轴上方
2. **年份**: 12px，黑色，居中
3. **年龄**: 12px，黑色，居中
4. **竖线**: 连接时间轴和事件区域
5. **事件列表**: 
   - 第一个事件可标注"（重大事件）"
   - 多个事件垂直排列，6px 间距
   - 编辑模式显示 "+" 号（灰色）

### 生命阶段标签
- **位置**: 顶部 40px 高度
- **字体**: 12px, 黑色
- **阶段**: 婴儿期、幼儿期、学前期、儿童期等
- **分隔线**: 垂直虚线，标记阶段边界

### "现在"标记
- **位置**: 根据当前年龄动态计算
- **样式**: 红色竖线，贯穿整个容器
- **文字**: "现在"，红色 (#c41616)，12px，旋转 90 度

### SVG 资源
- `line-vertical.svg`: 垂直竖线（事件连接线）
- `arrow-horizontal.svg`: 水平箭头（主时间轴）
- `line-event.svg`: 事件区域的竖线

## 动态数据绑定

### 需要动态生成的部分
1. **时间点数量**: 根据出生日期和当前日期计算
2. **年份和年龄**: 动态计算每个时间点
3. **重大事件**: 从用户数据中读取
4. **"现在"标记位置**: 根据当前年龄计算
5. **生命阶段标签**: 根据年龄范围动态显示

### 静态设计部分（从 Figma 提取）
1. **整体布局结构**
2. **字体和样式规范**
3. **SVG 图形资源**
4. **间距和尺寸规范**

## 实现策略

### 方案 1: Canvas 渲染（当前方案）
- 优点: 性能好，适合导出图片
- 缺点: 需要手动绘制所有元素，难以复用 SVG

### 方案 2: HTML/CSS + SVG（推荐）
- 优点: 可以直接使用 Figma 导出的 SVG，样式灵活
- 缺点: 导出图片需要额外处理

### 方案 3: 混合方案
- 使用 HTML/CSS 渲染，Canvas 用于导出图片
- 最佳平衡性能和灵活性
